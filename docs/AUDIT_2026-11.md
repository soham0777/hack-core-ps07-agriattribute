# AgriAttribute Technical Audit — November 2026

Scope: P0 items (yield attribution, ML pipeline, ROI engine) audited and fixed; data sources inventoried.
Method: code review of `app.py` and `services/`, plus an independent re-run of the model on
`data/field_trials.csv`. The saved Random Forest could not be loaded on the audit laptop (a Windows
Application Control policy blocks one scikit-learn DLL), so model checks used the pipeline's XGBoost
candidate retrained with identical settings (held-out R² 0.994, same as the production model).

## P0 findings

| # | Area | Finding | Impact | Status |
|---|------|---------|--------|--------|
| 1 | Attribution | Yield tab "SHAP attribution" donut was a hand-written formula (`weather = 0.36 + 0.04×rain/800 − 0.025×heat`), not model output | Displayed soil/weather/biological split had no link to the model | **Fixed**: model-derived additive decomposition + waterfall chart |
| 2 | Attribution | Scenario engine split untreated yield into a fixed 65% soil / 35% weather | Same as above | **Fixed** |
| 3 | Attribution | "Why this result?" impacts were constant strings (`+2.1 to +4.5`, `+1.8`, `-1.2`, `+1.5`, `+0.9` q/acre) | Same numbers for every farm | **Fixed**: values come from the decomposition |
| 4 | ML / dose | Each crop was trained at one dose only, so the model cannot learn dose-response; Soybean at 3 L jumped from 11.5 to **113 q/acre** (routed to Sugarcane leaves) | Any dose change in the Management tab could produce absurd yields | **Fixed**: model input pinned to the crop's trained rate; dose drives cost only |
| 5 | Units | Gram products (Taegro 150 g/acre, Vixeran 20 g/acre) were written into the model's L/ha input; Management tab dose is L/acre while the feature is named L/ha | Selecting Taegro broke the yield prediction | **Fixed**: unit stored with the dose; gram products priced from default pack cost |
| 6 | ROI | Biological cost was a flat ₹1,200 "per ha" regardless of dose, subtracted from per-acre revenue | ROI did not change with dose; unit mismatch | **Fixed**: ₹/acre = dose × ₹/L + application cost |
| 7 | Inputs | Season rainfall fixed at 780 mm for every crop; Rabi crops were trained on 30–460 mm | Every Rabi prediction was extrapolation | **Fixed**: per-crop training climatology (live rainfall still to do) |
| 8 | Inputs | GDD fixed at 2,350 regardless of temperature (training uses GDD ≈ 65 × temperature) | Inconsistent inputs | **Fixed** |
| 9 | Uncertainty | "Calibrated 90% band" was ±MAE pooled over all crops (±3.99) | Too wide for pulses, too narrow for sugarcane | **Fixed**: per-crop 90th-percentile held-out error |
| 10 | Scenarios | Scenarios 3 and 5 multiplied yield by unexplained 1.03 / 1.04 | Invented gains | **Fixed**: removed |
| 11 | Pipeline | Selected model (Random Forest) reported CV R² 0.9944 ± 0.015 — placeholder defaults; only XGBoost was cross-validated | Misreported validation | **Fixed in code**; needs a pipeline re-run to refresh `models/` |
| 12 | Metrics | Pooled R² 0.994 is driven by between-crop scale (8 vs 380 q/acre). Within-crop held-out R² is between −53 and 0.55 | Model mainly knows crop identity, not field differences | Reported per crop by the pipeline; needs real trial data |
| 13 | Data | `field_trials.csv` is generated by `pipeline/offline_training_pipeline.py` but labelled "ICAR AICRP & Syngenta Multi-Locational Trials" | Provenance claim not supportable | **Open**: relabel as simulated |

### Treatment-effect recovery (held-out 2025 experiments)

The simulated data stores each experiment's true lift, so recovery can be measured directly:
mean true lift 7.53 vs estimated 7.10 q/acre, correlation 0.86, MAE 3.39 q/acre.
By crop the estimate is weak for small-yield crops: Wheat 0.43 vs true 1.65, Mustard 0.21 vs 0.74,
Groundnut 0.02 vs 0.36. Expect negative ROI for those crops: the model under-detects their lift.

## Next work, by priority

- **P1 security**: the app sends the visitor's IP to two third-party services, one over plain HTTP (`ip-api.com`); move to HTTPS or browser geolocation with consent.
- **P1 data**: label the Agmarknet snapshot date in the UI instead of "Live"; use a single MSP year; wire season-to-date rainfall (IMD/Open-Meteo) and real NDVI.
- **P1 agronomy**: the simulated biological lift (4.5–15%) and the 4% "quality premium" on price need published trial evidence per product.
- **P2 vision**: LeafVision crop ID uses filename and aspect-ratio rules with fixed confidences; the MobileNetV3 backbone is loaded but unused.
- **P2 DevOps**: run `pytest tests` in CI; re-run the training pipeline to regenerate `models/` with the corrected CV reporting.
